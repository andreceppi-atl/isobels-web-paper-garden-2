# Isobel's Web — map-building practice

The world is a long shared page, not a competitive territory board. Navigation should feel like wandering through somebody's margin notes: mostly open, occasionally strange, and gradually marked by player silk.

## The five-room rhythm

| Room | Purpose | Current landmark | Traversal idea |
|---|---|---|---|
| 01 / bedroom edge | Safe arrival and identity | your page + leave a note | run, short jump, first wall |
| 02 / note yard | First social crossing | garden shelf | bridge a readable gap |
| 03 / quiet pond | Pause and listen | pond radio | broad swing bowl and low routes |
| 04 / signal hill | Vertical expression | signal post | climb, reel, release |
| 05 / old web | Shared destination | shared web | connect player strands into shortcuts |

Rooms are named in the minimap and in-world page labels. They are not locked stages; any spider can move backward, linger, or build an alternate route.

## Visual stack

1. **Paper:** warm near-white, uninterrupted wherever possible.
2. **Distant doodles:** repeated bedroom, garden, radio, pond, and web drawings at low opacity.
3. **Notebook guides:** faint horizontal rules and room dividers.
4. **Traversal cutouts:** pale paper solids with hard ink outlines and small hatch marks. Every visible edge remains attachable.
5. **Living layer:** monochrome spiders, messages, and player-made webs. Personal web color is the only sustained color accent.

Aim for roughly two-thirds blank space in any camera view. A landmark should be readable before the player reaches it, but scenery must never hide a grapple edge.

## Reusable room recipe

Each new room needs:

- one named social landmark;
- one calm floor where two spiders can stop together;
- one forgiving vertical question;
- one optional player-built shortcut;
- one return route that does not require a perfect swing;
- enough empty paper for webs and chat bubbles to become the decoration.

Do not use ownership gates, damage, races, or contested capture. Listening supplies Thread; Thread lets players add or maintain routes; those routes make the room feel more inhabited without excluding anyone.

Playtest traversal and social stopping points before carrying that geometry language into the other four rooms.
